# Unified Scoring Engine

Enterprise-grade scoring system and single source of truth for every score generated by the BIST Elite AI platform.

## Architecture

```
scoring_engine/
├── core/               # Types, enums, dataclasses
├── weights/            # Weight manager, profiles, horizon, regime
├── calculators/        # 16 score calculators + base ABC
├── optimizers/         # Weight optimization (rule-based)
├── validators/         # Input/output validation
├── profiles/           # Scoring profile manager (5 defaults + custom)
├── registry/           # Calculator registry (singleton)
├── cache/              # MD5 TTL + LRU cache
├── benchmark/          # Performance benchmarking
├── services/           # Service layer orchestration
├── schemas/            # 17 Pydantic v2 models
├── api/                # 13 FastAPI endpoints
└── tests/              # 187 tests
```

| `probability` | Statistical probability |
| `composite` | Weighted composite |

## 6 Weight Profiles

| Profile | Focus |
|---------|-------|
| Very Conservative | Quality, Financial, Risk (60%) |
| Conservative | Financial, Quality, Risk, Value |
| Balanced | Equal distribution across 12 types |
| Growth | Growth, Momentum, Technical |
| Aggressive | Momentum, Technical, Smart Money |
| Custom | User-defined weights |

## 5 Investment Horizons

Weekly → 1 Month → 3 Months → 6 Months → 12 Months

Short horizons boost momentum/technical. Long horizons boost financial/growth/quality.

## 5 Market Regimes

Bull → Bear → Sideways → High Volatility → Low Volatility

Each regime automatically adjusts weights (e.g., Bear boosts Risk/Quality, Bull boosts Momentum/Trend).

## Usage

```python
from modules.scoring_engine.services.service import ScoringService
from modules.scoring_engine.schemas.schemas import CalculateScoreRequest

service = ScoringService()

result = service.calculate(CalculateScoreRequest(
    symbol="TUPRS",
    metrics={
        "pe_ratio": 15.0, "roe": 12.0, "rsi": 45.0,
        "momentum": 3.0, "volume_ratio": 1.5,
    },
    profile="balanced",
    horizon="one_month",
    regime="sideways",
))
# result.composite_score = 67.5
# result.scores = {"financial": 72.0, "momentum": 65.0, ...}
# result.breakdowns = {score_type: ScoreBreakdown(...)}
```
